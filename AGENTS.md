# Company Lab contributor instructions

Create one educational 15–25 minute company case study per day, rotating geography, sector and financial condition. Write studies in src/content/studies/day-NNN-company.md with a unique studyNumber and valid frontmatter (see existing examples).

Every study should contain:
1. A description of who pays the company, for what, and how the business makes money.
2. A directly linked official annual filing and, if relevant, latest interim filing, clearly dated.
3. One actionable income-statement task, one balance-sheet task and one cash-flow task.
4. One synthesis question relating earnings, assets, cash, financial risks and the business model.

Prioritise source documents from investor relations, regulators and exchanges. Use exact periods and clarify unusual accounting metrics. Never invent financial figures, returns, filing links or live data. Explain the difference between company cash and stock valuation. Preserve reader exercises rather than filling in answers. Check existing posts to avoid repeating companies. For research updates, run npm run build and prefer a PR with review. Do not claim automatic publishing happens without an actual GitHub commit.
